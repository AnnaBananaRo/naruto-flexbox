# 忍術 Flexbox no Jutsu

**מגישות:** Anna Rotenshtein · Eden Kaushansky

משחק אינטרנטי שמלמד את המאפיינים הבסיסיים של CSS Flexbox, בעיצוב בהשראת נארוטו.

בכל משימה מסומנות על שדה האימונים **נקודות ציון**, והמטרה היא למקם עליהן את צוות 7
באמצעות בחירת ערכים לתכונות Flexbox – או כתיבת ה-CSS ישירות.

נבנה כמטלה בקורס **פיתוח אפליקציות אינטרנטיות**.

## קישורים

- **האתר החי:** https://AnnaBananaRo.github.io/naruto-flexbox/
- **הקוד:** https://github.com/AnnaBananaRo/naruto-flexbox

## איך משחקים

1. קוראים את תדריך המשימה.
2. בוחרים ערכים בתפריטים – שדה האימונים מתעדכן מיד.
   אפשר גם לכתוב את ה-CSS ישירות בתיבה שמתחת ללוח, עם השלמה אוטומטית.
3. לוחצים על **הפעל ג'וטסו** כדי לבדוק.
4. לא בטוחים מה המושגים אומרים? **מגילת הג'וטסו** בתחתית הפאנל מסבירה כל תכונה
   ואת כל הערכים שלה, והערך שנבחר כרגע מודגש בה.

## מה יש במשחק

| | |
|---|---|
| 9 משימות | בדרגות קושי עולות, 5 מהן משלבות יותר מתכונה אחת |
| התכונות הנלמדות | `display` · `flex-direction` · `justify-content` · `align-items` · `flex-wrap` |
| שתי דרכי משחק | תפריטי `select` או כתיבת CSS חופשית עם השלמה אוטומטית |
| מגילת הג'וטסו | הסבר על כל תכונה וכל ערך, עם הדגשה חיה של הבחירה הנוכחית |
| מערכת דרגות | מ-Academy Student ועד Hokage, לפי מספר המשימות שהושלמו |
| שמירת התקדמות | ב-localStorage, כולל חזרה למשימות שהושלמו וספירת ניסיונות |
| משוב ויזואלי | אנימציית צ'אקרה בהצלחה, רעידה אדומה בכישלון |
| רספונסיביות | שדה בגודל קבוע 600x400 בכל מסך, שמוקטן ויזואלית בלבד |

## הערה על גודל השדה

שדה האימונים הוא תמיד **600x400 פיקסלים**, בכל גודל מסך.
במסכים קטנים הוא רק מוקטן ויזואלית באמצעות `transform: scale`, כך שהמידות
הפנימיות שלו לא משתנות והפתרון של כל משימה נשאר זהה בכל רזולוציה.

## קבצים

| קובץ | תפקיד |
|------|--------|
| `index.html` | מבנה הדף |
| `style.css` | עיצוב האתר, שדה האימונים והרספונסיביות |
| `levels.js` | הגדרת הדמויות והמשימות (תדריך, מספר נינג'ות, פתרון) |
| `script.js` | לוגיקת המשחק, עורך הקוד, ההשלמה האוטומטית והדרגות |
| `images/` | אייקוני הדמויות (SVG) |

## טכנולוגיות

HTML, CSS ו-JavaScript בלבד – ללא ספריות חיצוניות וללא CSS Grid.

## קרדיטים

Naruto הוא יצירה של מסאשי קישימוטו. הדמויות והשמות משמשים כאן לצורכי לימוד בלבד
במסגרת מטלה אקדמית. **אייקוני הדמויות צוירו במיוחד לפרויקט הזה כקובצי SVG**
ואינם תמונות מהסדרה.
